# Paradise Nursery Shopping Application

An e-commerce shopping cart web application for an online plant shop called **Paradise Nursery**.

## Features
- Interactive landing page with company background and a "Get Started" button.
- Plant listing page featuring multiple categories of houseplants with detailed descriptions and prices.
- Shopping cart functionality powered by Redux Toolkit for managing item additions, quantity adjustments, and deletions.
- Dynamic cart counter and total cost calculation.
